# 服务器启动问题排查指南

## 可能的问题和解决方案

### 1. 端口占用问题
**症状**: `Error: That port is already in use`

**解决方案**:
```bash
# 使用其他端口启动
python manage.py runserver 8001

# 或者查找并关闭占用 8000 端口的进程
# Windows:
netstat -ano | findstr :8000
taskkill /PID <进程ID> /F
```

### 2. 缓存装饰器问题
**症状**: `TypeError` 或 `AttributeError` 相关错误

**当前实现**: 在 `goods/views.py` 中使用 `@method_decorator(cache_page(60))` 装饰 `list` 方法

**如果出现问题，可以临时移除缓存**:
```python
# 注释掉缓存装饰器
# @method_decorator(cache_page(60))
def list(self, request, *args, **kwargs):
    return super().list(request, *args, **kwargs)
```

### 3. 数据库连接问题
**症状**: `OperationalError` 或数据库相关错误

**解决方案**:
```bash
# 检查数据库文件是否存在
# SQLite 数据库路径: db.sqlite3

# 重新迁移（如果需要）
python manage.py migrate
```

### 4. 导入错误
**症状**: `ImportError` 或 `ModuleNotFoundError`

**已测试**: 所有导入正常 ✅

### 5. 配置错误
**症状**: `ImproperlyConfigured`

**检查项**:
- `settings.py` 中的 `INSTALLED_APPS` 是否正确
- `AUTH_USER_MODEL` 是否正确设置
- 缓存配置是否正确

## 快速诊断步骤

1. **检查系统配置**:
```bash
python manage.py check
```

2. **测试导入**:
```bash
python test_server.py
```

3. **查看详细错误**:
```bash
python manage.py runserver --verbosity 2
```

4. **使用不同端口**:
```bash
python manage.py runserver 8001
```

---

## 常见错误及解决方案

### 错误: `cache_page` 在 DRF 中不工作
**原因**: `cache_page` 是为 Django 视图设计的，在 DRF 中可能需要不同方式

**解决方案**: 使用 DRF 的缓存扩展或移除缓存装饰器

### 错误: 端口被占用
**解决方案**: 使用 `--noreload` 或更换端口

### 错误: 数据库锁定
**解决方案**: 关闭其他可能访问数据库的程序

## 建议的启动命令

```bash
# 标准启动
python manage.py runserver

# 指定端口
python manage.py runserver 8001

# 允许外部访问
python manage.py runserver 0.0.0.0:8000

# 详细输出
python manage.py runserver --verbosity 2
```
