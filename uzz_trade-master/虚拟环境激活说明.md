# 虚拟环境激活说明

## ⚠️ 问题
启动服务器时出现错误：
```
ImportError: Couldn't import Django. Are you sure it's installed and available on your PYTHONPATH environment variable? Did you forget to activate a virtual environment?
```

**原因**：未激活虚拟环境，Python 找不到已安装的 Django 包。

---

## ✅ 解决方案

### 方法一：使用批处理文件（推荐，最简单）

**Windows 用户**：
1. 双击 `启动服务器.bat` 文件
2. 会自动激活虚拟环境并启动服务器

---

### 方法二：手动激活（PowerShell）

**在 PowerShell 中执行**：

```powershell
# 1. 进入项目目录
cd d:\uzz-trade\uzz_trade-master

# 2. 激活虚拟环境
.\venv\Scripts\Activate.ps1

# 3. 启动服务器
python manage.py runserver
```

**如果 PowerShell 执行策略限制，先运行**：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

---

### 方法三：手动激活（CMD）

**在命令提示符中执行**：

```cmd
# 1. 进入项目目录
cd d:\uzz-trade\uzz_trade-master

# 2. 激活虚拟环境
venv\Scripts\activate.bat

# 3. 启动服务器
python manage.py runserver
```

---

### 方法四：使用 PowerShell 脚本

**在 PowerShell 中执行**：
```powershell
cd d:\uzz-trade\uzz_trade-master
.\启动服务器.ps1
```

---

## 🔍 验证虚拟环境是否激活

激活成功后，命令行提示符前会显示 `(venv)`：

```
(venv) D:\uzz-trade\uzz_trade-master>
```

## ⚠️ 常见问题

### 1. PowerShell 执行策略错误
**错误**：`无法加载文件，因为在此系统上禁止运行脚本`

**解决**：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 2. 虚拟环境不存在
**解决**：重新创建虚拟环境
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. 依赖包未安装
**解决**：
```powershell
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
