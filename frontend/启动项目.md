# ✅ 项目初始化完成！

## 🎉 安装成功

依赖已安装完成，现在可以启动项目了！

## 🚀 启动开发服务器

```bash
npm run dev
```

然后访问：**http://localhost:5173**

## 📋 可用路由

- **首页（商品列表）**: http://localhost:5173/
- **注册页面**: http://localhost:5173/register
- **登录页面**: http://localhost:5173/login

## ⚠️ 重要提示

### 1. 确保后端服务运行

在启动前端之前，确保后端 Django 服务正在运行：

```powershell
# 新开一个终端窗口
cd uzz_trade-master
.\venv\Scripts\Activate.ps1
python manage.py runserver
```

### 2. 测试流程

1. **启动后端**（端口 8000）
2. **启动前端**（端口 5173）
3. **访问前端页面**
4. **测试注册/登录功能**

## 📝 注意事项

- 有一些 npm 警告是正常的（deprecated 包），不影响使用
- 如果遇到端口冲突，修改 `vite.config.js` 中的端口号
- API 请求会自动代理到后端（`/api` → `http://127.0.0.1:8000/api`）

## 🐛 如果遇到问题

1. **端口被占用**：修改 `vite.config.js` 中的 `port: 5173`
2. **API 请求失败**：确保后端服务运行在 `http://127.0.0.1:8000`
3. **模块找不到**：删除 `node_modules` 和 `package-lock.json`，重新运行 `npm install`
