# Vue3 组件检查指南

## 🔍 检查方法

### 方法一：使用 ESLint 检查（推荐）

如果你已经配置了 ESLint，可以直接运行：

```bash
# 在 frontend 目录下
npm run lint

# 或者检查特定文件
npx eslint src/components/Register.vue
npx eslint src/components/Login.vue
npx eslint src/components/GoodsList.vue
```

---

### 方法二：使用 TypeScript/Volar 检查

如果你使用 VSCode 和 Volar 插件：

1. 打开组件文件
2. 查看编辑器底部的错误提示
3. 检查 Problems 面板（Ctrl+Shift+M）

---

### 方法三：运行开发服务器测试

```bash
# 1. 进入 frontend 目录
cd frontend

# 2. 安装依赖（如果还没安装）
npm install

# 3. 启动开发服务器
npm run dev

# 4. 在浏览器中访问并测试各个页面
```

---

### 方法四：手动代码审查清单

#### ✅ Register.vue 检查清单

- [ ] 导入是否正确：`import { authAPI } from '@/utils/api'`
- [ ] 表单字段是否完整：username, email, phone, student_id, college, password, confirmPassword
- [ ] 学号验证：`validateStudentId()` 函数是否正确
- [ ] 密码一致性验证：`validatePassword()` 函数是否正确
- [ ] 错误处理：是否处理了所有错误情况
- [ ] 成功跳转：注册成功后是否跳转到 `/login`
- [ ] 样式：是否使用了统一的 CSS 变量

#### ✅ Login.vue 检查清单

- [ ] 导入是否正确：`import { authAPI } from '@/utils/api'`
- [ ] 表单字段：username, password
- [ ] Token 存储：是否存储了 access、refresh、username
- [ ] 登录成功跳转：是否跳转到 `/`（首页）
- [ ] 错误处理：是否处理了登录失败的情况
- [ ] 样式：是否使用了统一的 CSS 变量

#### ✅ GoodsList.vue 检查清单

- [ ] 导入是否正确：`import { goodsAPI, authAPI } from '@/utils/api'`
- [ ] 登录状态检查：`checkLoginStatus()` 是否正确
- [ ] 商品列表加载：`loadGoods()` 是否正确
- [ ] 商品卡片展示：是否显示所有必要信息
- [ ] 所有者操作：编辑/删除按钮是否正确显示
- [ ] 路由跳转：点击卡片是否跳转到详情页
- [ ] 退出登录：`handleLogout()` 是否正确
- [ ] 样式：是否使用了统一的 CSS 变量
