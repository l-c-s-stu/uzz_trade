## 🚀 下一步操作

### 1. 安装依赖

```bash
cd frontend
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

然后访问：http://localhost:5173

### 3. 测试路由

- 首页：http://localhost:5173/
- 注册：http://localhost:5173/register
- 登录：http://localhost:5173/login

- ✅ Vue3 + Vite
- ✅ Vue Router（路由已配置）

## ⚠️ 注意事项

1. **确保后端服务运行**：
   ```bash
   cd uzz_trade-master
   .\venv\Scripts\Activate.ps1
   python manage.py runserver
   ```

2. **如果遇到端口冲突**，修改 `vite.config.js` 中的 `port: 5173`

3. **环境变量**（可选）：
   创建 `.env` 文件：
   ```
   VITE_API_BASE_URL=http://127.0.0.1:8000/api
   ```

## 🐛 常见问题

### 问题：npm install 很慢
**解决**：使用国内镜像
```bash
npm config set registry https://registry.npmmirror.com
```

### 问题：端口被占用
**解决**：修改 `vite.config.js` 中的端口号

### 问题：找不到模块
**解决**：确保已运行 `npm install`
