## 🐛 常见问题排查

### 问题 1: 组件无法导入

**症状**: `Cannot find module '@/utils/api'`

**解决**:
- 检查 `vite.config.js` 或 `vue.config.js` 中是否配置了路径别名
- 确保 `@` 指向 `src` 目录

### 问题 2: API 请求失败

**症状**: 网络错误或 CORS 错误

**解决**:
- 检查后端服务是否运行
- 检查 API 地址是否正确
- 检查 CORS 配置

### 问题 3: 路由不工作

**症状**: 点击链接没有跳转

**解决**:
- 检查路由配置是否正确
- 确保已安装 `vue-router`
- 检查路由路径是否正确

### 问题 4: 样式不显示

**症状**: 页面样式混乱

**解决**:
- 检查 CSS 变量是否正确定义
- 检查 `scoped` 样式是否正确
- 检查是否有样式冲突

## 💡 建议

1. **使用浏览器开发者工具**
   - F12 打开控制台
   - 查看 Console 标签页的错误
   - 查看 Network 标签页的请求

   - 可以查看组件状态、props、事件等

3. **逐步测试**
   - 先测试基本功能
   - 再测试边界情况
   - 最后测试错误处理
