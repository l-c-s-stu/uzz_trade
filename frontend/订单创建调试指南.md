# 订单创建失败调试指南

## 🔍 调试步骤

### 1. 打开浏览器开发者工具
- 按 `F12` 或右键点击页面选择"检查"
- 切换到 **Console（控制台）** 标签
- 切换到 **Network（网络）** 标签

### 2. 尝试创建订单
- 点击"立即购买"按钮
- 观察控制台输出和网络请求

### 3. 检查控制台输出
查看以下信息：
- `准备创建订单，数据:` - 检查发送的数据格式
- `商品ID类型:` - 应该是 `number`
- `商品信息:` - 检查商品状态是否为 `status: 1`（在售）
- `订单创建响应:` - 检查响应数据
- `创建订单失败 - 完整错误对象:` - 查看详细错误

### 4. 检查网络请求
在 Network 标签中：
- 找到 `POST /api/orders/` 请求
- 点击查看：
  - **Request（请求）**：
    - Headers（请求头）- 检查 Authorization token
    - Payload（请求体）- 检查 `goods_id` 是否正确
  - **Response（响应）**：
    - 查看返回的错误信息

## 🐛 常见问题

### 问题1: 商品ID无效
**症状**: `商品ID无效，请刷新页面重试`

**原因**: 路由参数解析失败

**解决**: 刷新页面，确保URL格式正确：`/goods/123`

---

### 问题2: 商品状态不是"在售"
**症状**: `商品状态为已出，无法购买` 或 `商品状态为下架，无法购买`

**原因**: 商品状态不是 `status: 1`（在售）

**解决**: 
- 只能购买状态为"在售"的商品
- 已出或下架的商品无法购买

---

### 问题3: 401 未授权
**症状**: `请先登录` 或 `Unauthorized`

**原因**: 
- 未登录
- Token 过期
- Token 格式错误

**解决**:
1. 检查是否已登录
2. 重新登录获取新 token
3. 检查 localStorage 中是否有 `access` token

---

### 问题4: 400 Bad Request
**症状**: `创建订单失败：商品状态为已出，无法购买` 或其他验证错误

**原因**: 后端验证失败

**可能的原因**:
- 商品状态不是"在售"
- 商品不存在
- 数据格式错误

**解决**:
1. 查看控制台中的详细错误信息
2. 检查商品状态
3. 刷新商品详情页面

---

### 问题5: 500 服务器错误
**症状**: `服务器错误 (500)`

**原因**: 后端服务器内部错误

**解决**:
1. 检查后端服务器是否正常运行
2. 查看后端日志
3. 检查数据库连接

---

### 问题6: 网络错误
**症状**: `网络错误，请检查网络连接`

**原因**: 
- 后端服务未启动
- 网络连接问题
- CORS 跨域问题

**解决**:
1. 确认后端服务运行在 `http://127.0.0.1:8000`
2. 检查网络连接
3. 检查浏览器控制台的 CORS 错误

---

## 📋 检查清单

创建订单前，请确认：

- [ ] 已登录（localStorage 中有 `access` token）
- [ ] 商品ID有效（URL 格式正确）
- [ ] 商品状态为"在售"（`status: 1`）
- [ ] 不是自己的商品
- [ ] 后端服务正在运行
- [ ] 网络连接正常

---

## 🔧 手动测试 API

可以在浏览器控制台手动测试：

```javascript
// 1. 检查 token
console.log('Access Token:', localStorage.getItem('access'))

// 2. 测试创建订单（替换 YOUR_GOODS_ID）
fetch('http://127.0.0.1:8000/api/orders/', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer ' + localStorage.getItem('access')
  },
  body: JSON.stringify({
    goods_id: YOUR_GOODS_ID,  // 替换为实际的商品ID
    post_script: ''
  })
})
.then(res => res.json())
.then(data => console.log('成功:', data))
.catch(err => console.error('失败:', err))
```
