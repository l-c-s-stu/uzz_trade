## ⚠️ 注意事项

### 1. 路由配置
确保在路由中正确配置了这些组件：
```javascript
{
  path: '/register',
  component: Register
},
{
  path: '/login',
  component: Login
},
{
  path: '/',
  component: GoodsList
}
```

### 2. 环境变量
在 `.env` 文件中配置 API 地址（可选）：
```
VITE_API_BASE_URL=http://127.0.0.1:8000/api
```

### 3. 依赖安装
确保已安装：
```bash
npm install vue vue-router axios
```
